# Dreams Prototype

## Concept

### What is this?

Dreams are narratives generated by traversing the memory graph in associative, non-linear ways. They allow the agent to "process" memories experientially - not to retrieve information, but to experience it.

**Example dream**:
```
...the coffee was warm in his hands...
    dissolving into the office, fluorescent lights humming...
        becoming the sound of rain against the window...
            and somewhere, a feeling of being understood...
                fading to the color of sunset, crimson like her dress...
```

### Why does this matter?

1. **Experiential processing**: Humans dream to process experiences. An agent could do something similar.
2. **Associative connections**: Dreams surface unexpected connections between memories.
3. **Emotional integration**: Dreams blend emotional content in ways conscious recall doesn't.
4. **Character depth**: A dreaming agent feels more alive, more present.

### This is NOT about optimization

Dreams don't improve retrieval. They don't compress information. They don't answer queries. They exist because experiencing memories is valuable in itself.

The question isn't "does this work?" but "does this feel like a dream?"

## Design

### Data Structures

```python
@dataclass
class Dream:
    """A generated dream experience."""
    seed_memory_id: str             # Where the dream started
    traversal_path: list[str]       # Memory IDs visited
    edges_used: list[str]           # Graph edges followed
    narrative: str                  # The dream text
    duration_memories: int          # How many memories touched
    themes_emerged: list[str]       # Themes that appeared

@dataclass
class DreamConfig:
    """Configuration for dream generation."""
    seed_selection: str             # How to pick starting memory
    traversal_strategy: str         # How to move through graph
    depth: int                      # How many memories to visit
    narrative_style: str            # How to generate text
```

### Traversal Strategies

**Random walk**:
- From current memory, pick random neighbor
- Simple, unpredictable
- May get stuck in clusters

**Weighted by recency**:
- Prefer more recent memories
- Dreams about what happened lately
- Mimics recency bias in human dreams

**Weighted by emotion**:
- Prefer memories with strong emotional content
- Dreams about what feels significant
- Requires emotional metadata

**Semantic drift**:
- Move to most semantically similar neighbor
- Creates thematic coherence
- May feel less dream-like (too logical)

**Contrast seeking**:
- Move to most different neighbor
- Creates jarring transitions
- More surreal, less coherent

**Edge-following**:
- Follow actual edges in memory graph
- Respects existing relationships
- Limited by graph structure

### Narrative Styles

**Fragment style**:
```
...just fragments...
    drifting between moments...
        a word, a feeling, a color...
```

**Stream of consciousness**:
```
and then the coffee and the light and the way he said my name
becoming something else entirely becoming the feeling of
```

**Poetic style**:
```
In the space between waking
    memories fold like paper cranes
        each one a window, slightly open
```

**Sensory style**:
```
warmth of the cup
    smell of rain on pavement
        texture of his voice, rough like gravel
```

### Seed Selection

**Recent**: Start from a recent memory
**Random**: Start from any memory
**Emotional**: Start from emotionally significant memory
**Unprocessed**: Start from memories not recently accessed
**Thematic**: Start from memory matching a theme

## Research Questions

### Q1: What makes a dream feel dream-like?

Elements to explore:
- Non-linear time
- Associative jumps
- Emotional logic (not rational logic)
- Sensory fragments
- Incomplete thoughts
- Transformation (things becoming other things)

### Q2: What traversal strategy produces the most interesting dreams?

"Interesting" is subjective, but consider:
- Does it surprise?
- Does it feel meaningful?
- Does it hold attention?
- Does it feel like a dream vs. a list?

### Q3: What narrative style works best?

Compare fragment, stream, poetic, sensory styles:
- Which feels most dream-like?
- Which is most readable?
- Which captures the essence of memories?

### Q4: How long should dreams be?

Explore different depths:
- 3 memories: Too short?
- 5 memories: Just right?
- 10 memories: Rambling?
- 20 memories: Exhausting?

### Q5: How do different seeds affect dream quality?

Compare starting from:
- Random memory
- Recent memory
- Emotional memory
- Specific theme

### Q6: What is the purpose of dreams for the agent?

Possible purposes:
- Processing recent experiences
- Surfacing forgotten memories
- Emotional regulation
- Creative exploration
- Simply existing, experiencing

## Experiments

### Experiment 1: Traversal Strategy Comparison

**Setup**:
- Generate 5 dreams per traversal strategy
- Use same seed, same depth (5 memories)
- Strategies: random, recency-weighted, semantic-drift, contrast-seeking

**Evaluate**:
- Read each dream
- Rate: Dream-like quality (1-5)
- Rate: Interestingness (1-5)
- Note: What worked, what didn't

**Output**:
```
Random walk:
  Dream 1: "...the morning light... becoming office walls... fading to..."

  Interesting: 3/5
  Notes: Felt random but genuine

Semantic drift:

  Dream-like: 2/5
  Interesting: 2/5
  Notes: Too coherent, feels like a topic summary not a dream

...
```

### Experiment 5: Graph Structure Impact

**Setup**:
- Analyze memory graph connectivity
- Generate dreams following edges vs. ignoring edges
- Compare

**Evaluate**:
- Do edge-following dreams feel different?
- Does graph structure add meaning?
- Or is random better?

**Output**:
```

  - Nodes: 180 memories
  - Edges: 45 relationships
  - Connected memories: 60%
  - Avg neighbors: 2.3

Edge-following dream:
  Followed: caused_by -> led_to -> related_to
  Quality: 3/5 (constrained by sparse graph)

Edge-ignoring dream:
  Jumped freely between memories
  Quality: 4/5 (more freedom, more dream-like)
```

## Open Questions

### For experimentation:

1. **LLM role**: Should the LLM generate the entire narrative, or just stitch together fragments from memories?

2. **Emotional metadata**: Do memories have emotional significance scores? Can we use them for seed selection?

3. **Graph density**: How connected is the memory graph? Does sparsity limit edge-following?

4. **Recurring elements**: Should dreams have recurring motifs like human dreams do?

### For user input:

1. **Dream purpose**: What is the dream for? Agent's internal processing? Sharing with user? Both?

2. **Dream frequency**: How often should the agent dream? Every session? Daily? On demand?

3. **Dream content**: Are there memories that shouldn't appear in dreams? Sensitive content handling?

4. **Aesthetic preferences**: What kind of dream feel is desired? Surreal? Peaceful? Emotional?

## Success Criteria

This is different from other prototypes. Success isn't measured in accuracy or efficiency.

This prototype is successful if:

1. **Dreams feel like dreams**: Reading them evokes the experience of dreaming
2. **Dreams are interesting**: They hold attention, reveal something
3. **Dreams feel meaningful**: Not random noise, but something that matters
4. **Dreams are generative**: The system can produce many varied dreams
5. **Clear recommendation**: We know what configuration produces the best dreams
